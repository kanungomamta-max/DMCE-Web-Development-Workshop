# Day 4 — Modern Web Development

Open `index.html` with Live Server.

Learning goals:
- JSON data
- Fetch API
- async/await
- Dynamic rendering
- localStorage
- Search
- Theme toggle
- Error handling

Important:
Run through Live Server. Do not double-click `index.html`, because Fetch may be blocked by the browser's local-file security rules.

Student challenges:
1. Add a fifth event to `events.json`.
2. Add a category filter.
3. Store a participant name with the saved plan.
4. Add a total planned budget.
5. Discuss where an API would replace the local JSON file in a real application.
