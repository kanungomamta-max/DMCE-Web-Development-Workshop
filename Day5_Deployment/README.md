# Day 5 — Deployment & Showcase

Open `index.html` with Live Server.

Learning goals:
- Production readiness
- Deployment checklist
- Git/GitHub workflow
- Static website hosting concepts
- Browser and responsive testing
- Production validation
- Presenting the finished project

Suggested instructor flow:
1. Run the site locally.
2. Demonstrate the checklist.
3. Explain Git → GitHub → deployment.
4. Show the deployment flow.
5. Discuss AWS/Azure/static hosting options conceptually.
6. Have students present their mini project.

Suggested deployment discussion:
- Static hosting: HTML/CSS/JS can be hosted without a backend.
- GitHub: source/version control.
- Cloud hosting: publish the built website.
- Production test: verify links, assets, responsive behaviour and console errors.
