# DMCE Web Development Workshop — 5 Day Independent Demo Codebase

Each day is an independent project. Open the day's folder in VS Code and run `index.html` with Live Server.

## Day 1 — HTML
`Day1_HTML/`
- Semantic HTML
- Images
- Links
- Tables
- Lists
- Forms

## Day 2 — CSS
`Day2_CSS/`
- Visual design
- Box model
- Flexbox
- Grid
- Hover effects
- Responsive CSS

## Day 3 — JavaScript
`Day3_JavaScript/`
- DOM
- Events
- Search
- Filtering
- Modal
- Form handling

## Day 4 — Modern Web
`Day4_ModernWeb/`
- JSON
- Fetch API
- async/await
- localStorage
- Dynamic UI
- Theme toggle

## Day 5 — Deployment
`Day5_Deployment/`
- Production checklist
- Git/GitHub discussion
- Deployment flow
- Responsive validation
- Showcase

## Setup
1. Install Visual Studio Code.
2. Install Live Server extension.
3. Open one day folder in VS Code.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

The projects use local SVG illustrations, so no external image downloads are required.
